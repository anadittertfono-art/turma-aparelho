# Aparelho · Jogos da Turma

Página de apoio dos jogos de Ana Letícia Dittert (fonoaudióloga, CRFa 2-9308-3), publicada no GitHub Pages:
https://anadittertfono-art.github.io/turma-aparelho/

Os jogos ficam no Google Sites, que esquece tudo o que o jogo guarda a cada visita. Esta página fica sempre no mesmo endereço, então o que ela guarda no aparelho permanece.

- `?j=<jogo>` (invisível, dentro de cada jogo): conta o aparelho na planilha da Ana no máximo uma vez por dia e por jogo, e avisa o jogo se o aparelho foi marcado como da Ana. Nesse caso, nada é contado.
- `?modo=ana` (visível): marca ou desmarca o aparelho como da Ana. É aberto pelos 5 toques no título da página "Materiais gratuitos".

Guarda no aparelho só a data da última visita a cada jogo e a marca da Ana. Não envia nome, conta, IP nem identificador do aparelho.

Antes ficava numa página do Apps Script. Ela dava erro ("Não foi possível abrir o arquivo") em navegadores com mais de uma conta do Google conectada.

O código dos jogos fica num repositório privado separado (`jogos-da-turma`).
